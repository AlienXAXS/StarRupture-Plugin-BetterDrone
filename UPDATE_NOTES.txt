- Press C (rebindable) on the map in the drone to switch between your character and the drone
- Ctrl + mouse wheel switches your hotbar page while the drone is out. Arrives with the upcoming game update; does nothing on the current game version. Ctrl is also the default Slow key, so the drone slows while you scroll; rebind Slow Key on the Config page if you prefer
- The number keys pick the hotbar slot with the same number (1-9 and 0) while the drone is out, building slots only, and the mouse wheel steps to the next or previous building slot. Weapon, consumable and empty slots are skipped. While you are placing a building the wheel stays with the game. Once a building is in hand the wheel belongs to the game, so use the number keys or put it away to pick another slot. Arrives with the upcoming game update; does nothing on the current game version
- Two new options for the hotbar on foot: Number Keys Pick Hotbar On Foot (on by default) selects the slot in delete mode, where the game has no number key, and Mouse Wheel Picks Hotbar On Foot (off by default, so the game's own weapon wheel is kept) steps to the next or previous building or weapon slot. Arrives with the upcoming game update; does nothing on the current game version
- New option Esc Opens Pause Menu In Drone Mode (off by default): Esc opens the pause menu in the drone instead of recalling it; Q still recalls
- New speed preset Light Construction (1450 cm/s, 2.25x boost), halfway between Stock and Better Construction
- Q or B with a new building in hand ends the placement and keeps you in the drone; moving an existing building still snaps back
- Q or B with the building menu open closes the menu and keeps you in the drone, on the game version where the menu needs it
- Needs ModLoader 1.24.0 or newer. The hotbar parts (the number keys and the wheel picking hotbar items, and the Ctrl+wheel hotbar page) arrive with the upcoming game update and do nothing on the current game version
